# l2k_gps3d — FiveM 向け 3D GPS ルート描画プロトタイプ

FiveM 用の 3D GPS レンダラープロトタイプです。

[デモ動画はこちら](https://youtu.be/uJbZZwEVIng)

このリソースは次のことを行います。

- ゲーム内でアクティブな GPS ルートを読み取る
- `GET_POS_ALONG_GPS_TYPE_ROUTE` でルート上の位置をサンプリングする
- 道路上空に、線と方向 chevron による 3D トレイルを描画する

### インストール

1. `l2k_gps3d` フォルダを `resources` ディレクトリにコピーする
2. `server.cfg` に `ensure l2k_gps3d` を追加する
3. サーバーを起動する

### 使い方

1. マップにウェイポイントを設定する
2. 車両に乗る
3. 現在のアクティブルートに基づいて 3D GPS が描画される
4. 必要に応じて下記コマンドを使用する

### コマンド

- `/gps3d` — 3D GPS の ON / OFF
- `/gps3d_refresh` — ルートの再構築を強制する
- `/gps3dcolor r,g,b,a` — 色を変更する
- `/gps3dtype 1 or 2` — 描画タイプ（1 = 線、2 = rect+uvmap（ytd / png））
- `/gps3ddebug` — Native Z / 地面まわりのデバッグ（クリッピング、地下ポイント、ルート高さの検証用）

### 注意事項

- ビジュアルプロトタイプであり、デフォルトのミニマップ GPS の代替にはなりません
- スクリプトは GTA / FiveM が既に計算したルートを利用します
- ジャンクションのフィルタとカーブ連続性の第一版を含みますが、一部のカーブでは軽微な描画アーティファクトが残る場合があります
- 実行環境で `GetPosAlongGpsTypeRoute` が利用できない場合、コンソールに警告が出ます
